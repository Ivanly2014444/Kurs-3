
# Проект «Sky is Over»: Мониторинг воздушного пространства

### Приложение в реальном времени собирает данные о местоположении и скорости гражданских самолетов, находящихся в воздушном пространстве выбранных стран, и сохраняет эту информацию в базу данных PostgreSQL для последующего анализа.

# Функционал приложения

* Сбор геокоординат: Определение географических границ (bounding box) стран с помощью Nominatim API.
* Трекинг авиации: Получение списка активных воздушных судов внутри границ этих стран через OpenSky Network API.
* Сохранение и обновление: Запись данных в СУБД PostgreSQL. При повторном обнаружении самолета обновляются его текущие координаты и скорость.
* Аналитический блок: Вывод статистики по количеству самолетов над страной, расчет средней скорости полета, фильтрация быстрых судов и поиск по ключевым словам в позывном авиакомпании.

# Архитектура и структура модулей

* main.py - Главный файл, координирующий последовательный запуск модулей, обработку циклов по странам и аналитику.
* config.py - Модуль для парсинга конфигурационного файла и безопасного извлечения параметров подключения к БД.
* api_client.py - Файл, отвечающий за выполнение HTTP-запросов к сторонним API и валидацию ответов.
* db_loader.py - Инициализатор базы данных, выполняющий безопасное пересоздание структуры таблиц перед началом работы.
* db_manager.py - Класс для работы с сохраненными данными, инкапсулирующий сложные SQL-запросы (агрегацию, фильтрацию с подзапросами и JOIN-соединения).
